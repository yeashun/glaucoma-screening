GitHub Actions配置会在推送后安装固定CPU目标框架，重新运行11项检查、22项ACRIMA测试和公开文件检查。首次云端运行状态以仓库Actions页面为准；本文件记录的是发布前已完成的本地/服务器核验。

源码整理仅涉及目录、编码、旧入口缩进、可配置CPU数据路径及公开版标准Pillow后备路径。比赛的98.13分与80.203ms是原项目历史结果，不是这些合成测试测出的指标。原生图像处理环境或GPU变化后仍需重新核验；未完成官方T4验收的状态保持不变。
