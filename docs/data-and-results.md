# 数据、公开范围与结果口径

比赛题目为彩色眼底图像二分类，输出阳性概率，标签0为阴性、1为阳性。主指标AUROC；辅助指标AUPRC。公开赛题给出的训练、验证、测试规模分别为51,396、5,849、5,855张。年龄是辅助临床字段，最终模型没有使用年龄。

比赛数据与信息受到使用、传播限制。本仓库不上传眼底图像、官方CSV、真实样本ID清单、逐图预测、训练后权重、缓存或比赛提交材料。代码中的字段名称用于说明接口；所有测试图像和测试标签都由测试程序临时合成。复现者应自行从主办方取得合法访问权限。

ACRIMA研究使用另一套数据和固定划分，训练内部三折，另设校准集与最终测试集。代码保留该协议，但同样不在仓库分发图像、实际清单或训练产物。它没有进入比赛模型的预训练、微调、融合拟合或测试。

## 字段接口

| 比赛字段 | 用途 |
| --- | --- |
| `Image_name` | 图像文件名及输出对齐键 |
| `True_Label` | 训练/验证监督标签，0或1；测试没有该列 |
| `Age` | 辅助年龄；使用时仅从相应训练子集拟合填补/标准化参数 |
| `Probability` | 输出阳性概率，范围[0,1] |
| `Pred_Label` | 按固定0.5阈值得到的类别 |

## 正确解读结果

- AUROC基于连续预测排序，不能用分类准确率替代；98.13是官网显示分数。
- AP和对PR曲线作梯形积分的AUPRC不是同一个数，仓库分别记录。
- 验证集比较、训练内部OOF、官网测试与独立ACRIMA测试对应不同数据角色，不能放在同一排行榜比较。
- 正式训练中官方验证集未并入训练；OOF的外折没有用于checkpoint选择；融合标准化和系数只拟合训练OOF。
- 加速前后官网显示分数相同，不代表未四舍五入AUROC、并列关系或每个概率逐位相同。
- 80.203ms只对应记录的4090、原生并行Pillow、软件版本和自选集合，不能外推到T4或公开版默认标准Pillow路径。

项目作者于2026-11-06反馈新版官网仍为98.13分；本仓库没有附官方后台截图、精确未舍入指标、比赛名次或获奖声明。方法文档、原始实现和聚合结果可以互相核对，但没有公开数据与训练权重时不能独立复算这一官网成绩。
