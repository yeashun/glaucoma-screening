# 方法设计

## 输入与确定性预处理

输入是彩色眼底图像，输出为青光眼阳性概率。图像经过EXIF方向校正、RGB转换、单图黑边区域估计、等比例补边至384×384，再采用固定ImageNet归一化。黑边阈值与补边方式固定，不从测试集汇总或拟合参数。

训练使用水平翻转、±15°旋转和轻度ColorJitter。Gamma分支另外以0.2概率使用0.9～1.1的Gamma变换；推理时全部随机增强关闭。最终组合没有年龄分支、TTA或患者级平滑。

## 模型与损失

C00和Gamma均为ConvNeXt-Tiny：池化特征→128维分类头→ReLU→Dropout→单logit。两路从同来源ImageNet初始化独立训练；普通BCE、自然采样、有效batch32，首轮冻结骨干，其后微调。最终采用C00/seed42第9轮与Gamma/seed42第6轮。

独立排序实验从E00最佳权重继续微调，目标为：

\[
\mathcal L = \mathrm{BCE}(z,y) + \lambda\,\mathbb E_{i\in +,j\in -}\big[\mathrm{softplus}(z_j-z_i)\big].
\]

排序项只接受同时包含两类的批次，在FP32 logit上计算；保留独立排序批次、AMP状态及空类检查。本次继续微调没有超过E00，因而没有进入最终融合。

## 训练集OOF融合

训练数据分为五个外折；每个外折的训练部分再留内部验证，用内部验证选择epoch。外折仅用于产生未见样本的预测。重复风险簇尽量放在同一折，但没有真实患者ID，不能声称完成患者级独立验证。

两路OOF概率先裁至[1e-6,1−1e-6]，转换为logit，再用训练OOF估计均值和标准差。固定L2=0.001的Logistic回归学习截距与两个系数：

\[
p = \sigma\!\left(b + \sum_{m=1}^{2}w_m\,\frac{\operatorname{logit}(p_m)-\mu_m}{s_m}\right).
\]

官方验证集仅用于报告和比较，没有参与这些系数或统计量拟合；测试集没有参与训练、融合拟合或阈值选择。融合之前检查五折覆盖、标签、分区SHA、checkpoint来源和预测SHA。

## 加速与一致性

最终工程版本减少全尺寸图像的重复复制；Pillow派生源码只并行独立输出行与新建、界内裁剪的内存复制，保留原来的整数像素运算。GPU端用固定batch=1 CUDA Graph记录双模型操作调度，每次拷入新图像张量，不缓存图像或预测。前向FP16、sigmoid FP32、融合float64。

`competition/deployment/cost.py`导入`code/predict.py`的同一个Predictor。端到端计时包括文件读取、解码、预处理、前向、融合和CSV写出；加载、初始化和5张预热不计时。100张串行运行3轮，先对每张取均值，再对100张取均值。

一致性同时检查二值标签、所有样本间排序（含并列）和≤1e-3概率误差。概率接近不意味着排序一定不变：曾尝试的Pillow-SIMD候选在100张中出现11张不一致，最终放弃。

当前加速版完整推理5855张后重新提交，官网显示仍为98.13分。与旧batch=32 CSV有微小概率及排序/并列变化，因此保留两份结果，不把相同显示分数解释成所有概率或未四舍五入AUROC完全相同。
