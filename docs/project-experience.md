# 项目经历表述

以下内容按已有代码和实验结果撰写。具体团队角色、个人分工、比赛名次与奖项应按实际情况补充，不能由本项目代码推断。

## 简历精简版

**青光眼眼底图像二分类与推理优化｜PyTorch、ConvNeXt、OOF Stacking**

- 构建眼底图像二分类训练与评估流程，覆盖可变尺寸预处理、数据重复风险审计、不均衡指标、断点续训和实验配置管理。
- 通过骨干、增强、分辨率、年龄及EMA消融，形成C00＋Gamma双路ConvNeXt-Tiny方案；使用训练集五折OOF拟合冻结Logistic融合，验证AUROC达到0.987405，官网显示成绩从97.23提升到98.13分。
- 统一预测与计时入口，采用FP16、CUDA Graph及保持原像素计算的图像行并行；RTX4090自选100张、batch=1连续3轮端到端均值80.203ms，与新版提交CSV标签和排序零不一致，官网显示成绩保持98.13分。

上述耗时属于4090辅助自测，尚未完成官方T4复测；不宜写成“在T4上达到80ms”。没有比赛名次证据时，不写“冠军”“Top X%”等表述。

## 面试展开顺序

1. **任务难点**：阳性稀少、图像尺寸和采集条件差异大；为什么以连续排序指标而非准确率选模。
2. **实验取舍**：为什么排序损失、更大分辨率、Age或EMA没有全部叠加；单种子增益与稳定性复核的区别。
3. **融合可信度**：OOF由外折未见样本产生，内部验证选epoch；标准化和融合系数为什么不能在官方验证或测试集上拟合。
4. **性能优化**：先区分CPU图像处理与GPU前向；缓存操作调度与缓存图像/预测的区别；为什么因排序变化放弃更快的SIMD候选。
5. **交付边界**：官网显示成绩、验证指标、4090耗时和T4正式验收如何分别留证；公开代码为什么不附真实比赛数据。

独立ACRIMA模块可补充介绍交叉验证、温度校准、阈值固定和测试锁定。它是另一套研究流程，不可写成比赛训练用了ACRIMA来提升成绩。
